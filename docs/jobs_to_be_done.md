# Jobs To Be Done (JTBD): OmniCalc Suite

This document defines the high-level Jobs To Be Done for each user role. Each job articulates what the person needs to accomplish regardless of the software tool used, avoiding UI mechanics, screens, or specific button references.

---

## Jobs To Be Done Catalog

- **Job J-1 (Everyday Consumer)**. "When evaluating prospective retail purchases against personal spending limits, I want to calculate the true final cost after merchant markdowns and statutory tax obligations, so I can confirm affordability and avoid checkout surprise."

- **Job J-2 (Prospective Homebuyer)**. "When evaluating residential properties to purchase, I want to project my total monthly carrying expenditure across principal, interest, taxes, and ongoing ownership fees, so I can ensure the ongoing payment fits comfortably within household cash flow."

- **Job J-3 (Prospective Homebuyer)**. "When planning the repayment strategy for long-term residential debt, I want to calculate how paying extra principal each month reduces lifetime interest expense and shortens the loan duration, so I can pay off my mortgage years ahead of schedule."

- **Job J-4 (Desk Worker)**. "When reconciling expense reports, invoices, or numerical ledger entries, I want to execute multi-step arithmetic while retaining interim totals and an audit trail of past calculations, so I can verify numerical accuracy without manual recalculations."
